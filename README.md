# 备考台

一个本地运行的备考网站，目前装了两个考试：**CET-6** 和 **349 药学综合（沈阳药科大学）**。左侧栏顶部可以切换。

共同的设计目标：不是"检验你能考多少分"，而是**用最短时间把东西学会**——默认给方向、给定位，但**答案要你自己一层层揭开**。

## 怎么用

双击 `index.html` 即可，不需要联网、不需要装任何东西。建议在 Chrome 或 Edge 里打开（朗读功能需要系统语音）。

第一次进来先选考试：

- **CET-6**：会被引导做一次诊断，78 个词的词汇量测算（约 5 分钟）+ 8 道习惯问卷，自动生成训练方案。只做一次。
- **349**：直接进总览，选「带背」开始，或先翻「学霸笔记」建立骨架。

## 三个开关（顶栏常驻）

- **划词提示**：划到单词弹释义；划到句子，页面底部显示整句翻译。内置 322 条词典，收录的词带虚线下划线。
- **辅助提示**：四档
  - `模拟考试` = 什么都不给，做完才看解析
  - `轻` = 只给题型标签 + 该类题的解题口诀（不剧透）
  - `中` = 再加"去哪一段找"（默认）
  - `强` = 连正确答案和解析一起显示
- **即时反馈**：选完立刻判对错，不用等交卷

推荐流程：第一次「强」→ 隔天「中」→ 考前「模拟考试」。

## 效率工具（做题页）

做题页顶部有一条工具条：计时（超过建议时间会变红）、已答计数、逐句翻译、快捷键。

**宽屏（≥1160px）自动双栏**：左边文章、右边题目，各自独立滚动，不用来回翻。

### 划词与整段翻译

- **划选任意文字**就会浮出一条小工具条：`收词` / `翻译` / `复制`
  - 划的是**单个英文单词** → 「收词」可用
  - 划的是**任意一段** → 「翻译」可用
- **收词自动带例句**：存进生词本时会把**那句话一起存下来**（原文 + 译文 + 出自哪一篇），速记卡和生词本里都能看到，目标词在例句里**高亮标黄**。生词本表格点「例句」展开
- **整段翻译**：优先用句子自带的译文做**逐句对照**（左原文右译文，选了几句就列几句）；这段没内置译文时，配了 AI 接口就走 AI 翻译，没配会明说
- 快捷键：`S` 收词 · `R` 翻译划选的整段 · `T` 展开/收起全文逐句译文

### 辅助提示系统

四档：`模拟考试`（无提示）/ `轻 · 方向` / `中 · 定位` / `强 · 全开`。档位决定的是**最多能开到第几级**，不是一口气全摊开。

- **按需逐级揭示**：做题时只先给「方向」。真的卡住了再点「还是没思路 → 告诉我在哪一段」，还不行才点「实在不会 → 看思路」
- **提示 3 只给思路，不直接报答案**——答案提交后自己核对。直接看答案练不出东西
- **提示记账**：每道题用了第几级提示都记下来。提交后会告诉你「这 N 题你开了提示，其中 M 题做对——这几题的分不算真会」，并给出**不开提示的正确率**，那才是你的真实水平
- **自适应建议**：最近无提示正确率 ≥80% 会建议收紧档位逼自己；≤45% 会建议放宽先把方法学会。统计页也能看到，可以「先不用」
- **错题重做自动升档**：从错题本点「只重做这几道」时，如果你当前档位低于「中 · 定位」，自动开到那一档（不覆盖你主动调高的设置）

### 逐层揭示解析（按 `E`）
不直接把答案拍在你脸上。四层，一层层点开：

1. **题型方向** —— 这类题该怎么想
2. **去原文哪里找** —— 定位提示
3. **可以先排除谁** —— 干扰项为什么错
4. **答案与完整解析** —— 这时候才给答案

### 其他辅助
- **定位原文**（`L`）：按题目里"原文依据"在文章里模糊匹配，黄色高亮并滚动过去
- **逐句翻译**（`T`）：一键展开全部句子译文，不用一个个 hover
- **题眼高亮**：题干里 mainly / infer / attitude / except 这类决定题型的词标红
- **绝对化词预警**：选项里 all / never / only / must 这类词加波浪线，通常可以先排除
- **错因自评**：每道错题下面点「定位错 / 句子没拆开 / 词汇卡住 / 粗心」，三种错法补法完全不同，会统计到数据分析页
- **收词**：选中任意单词按 `S`（或鼠标停在上面按 `S`）收进生词本

## 学习引擎

- **答题记录**：每次提交按题型记录，算正确率
- **六级得分预估**：按真题分值折算（讲座/仔细阅读 14.2 分每题、长对话/篇章/匹配 7.1、选词 3.55），没测过的题型用总正确率兜底并标「未测」；写译按全国平均 130 估
- **SRS 生词本**：SM-2 简化算法，三档评分（忘了 / 模糊 / 记得）决定下次复习间隔
- **错题库**：做错进库，连续做对 2 次毕业
- **打卡**：连续天数、70 天热力图、每日目标（15 / 30 / 50 / 80 题可调）

### 349 药学综合模块

沈阳药科大学自命题。**有机化学 + 分析化学 + 生物化学，每门 100 分，满分 300 分，题型不限**（2025 年起取消生理学，题型也不再是纯客观题）。

参考教材：胡春《有机化学》三版、邸欣《分析化学》八版、姚文兵《生物化学》八版。

### 带背（核心功能）

照着 B 站带背 up 主的思路做的：快、循环、可听、能挖空。

- **三种模式**
  - `跟读`：显示全文 + 朗读，跟着念
  - `填空`：自动把关键片段挖成空，先自己想，再对答案
  - `听背`：文字直接遮住，只放音，逼自己回忆
- **可调**：语速 0.7–1.5x、每条读 1–3 遍、条间 0.5–4 秒
- **范围**：全部 / 只背高频（常考指数 5 星）/ 只背收藏 / **只背不会+模糊** / **只背没标记过的** / 按科目 / 按单章
- **默写**：填空与听背模式下可以**打字作答**再对答案，系统用中文二元组覆盖率判分，告诉你命中了几个关键词、漏了哪段
- **自评**：每条都能标 `不会 / 模糊 / 会`，标记直接进入掌握度；标完自动跳下一条，适合一轮一轮刷
- **自动往下走**，背完一轮停住；进度记在本机，下次接着背
- **收藏**：按 `F` 收藏，之后可以只循环背收藏的

快捷键：`空格` 播放/暂停 · `←` `→` 切条 · `D` 显示答案 · `F` 收藏 · `1` `2` `3` 标不会/模糊/会

> 朗读用浏览器的语音合成。如果没装中文语音包会读不出来，页面底部会提示怎么装。

### 掌握度与错题本（学习闭环）

做题和带背不再各干各的，都汇到同一个账上：

- **掌握度** = 答题正确率（60%）+ 带背自评（40%），两者都有才算数，没测过的章显示「未测」
- 总览页、笔记页、章节页、顶栏都能看到；掌握度页按科目列出每章的掌握度，并直接点出**最薄弱的 3 章**
- **错题本**：做错自动进来，**连对 2 次自动毕业**，也可以手动标「已掌握」。每道错题下面直接带解析要点，一键跳回该章重做或去背
- 没选答案就点「查看解析」**不会**被判成错，避免一键把整章塞进错题本
- 349 的记录和 CET-6 完全分开，清空互不影响

### 学霸笔记

一句话一条，不废话。每条结构：

```
关键词   结论（一段说清）
         口诀：……（方便背）
         易错：……（常见丢分点）
```

章节按常考指数标了 5 格热度条，总览页直接列出「最该先背的 8 章」。

### 反应机理（有机）

有机化学的分基本都在机理上。每个机理拆成三段看：

1. **分步**：每一步发生了什么
2. **箭头**：电子从哪流向哪（"谁进攻谁"）
3. **考点**：这个机理真正考的是什么、常见的坑

有机目前 **27 个机理**：自由基卤代、烯烃亲电加成（马氏）、过氧化物效应、溴鎓离子反式加成、Diels-Alder、共轭二烯 1,2/1,4、苯的亲电取代、傅-克烷基化重排、SN1/SN2 对比、E2 消除、醇的酸催化取代、酚的酸性、环氧乙烷酸碱开环（取向相反）、Claisen 重排、频哪醇重排、亲核加成、羟醛缩合（含脱水与交叉缩合）、Cannizzaro、卤仿反应、Michael 加成、Wittig、Baeyer-Villiger、酯化、Claisen 缩合、Beckmann 重排、重氮化。

有机另有三章「方法论」：**命名**（官能团优先顺序 / Z,E / 苯侧链母体判断）、**杂环化合物**（五元富电子 vs 六元缺电子、芳香性来源、五元取代在 2-位、吡啶亲核取代在 2/4-位、吲哚 3-位、稠环位置、酮-烯醇互变、常见药环辨识）、**合成与逆合成**（切断法、碳链增减、丙二酸酯 vs 乙酰乙酸乙酯、保护基、氧化放最后、先氧化后硝化的顺序陷阱）。

> **范围按沈药 349 走：不含波谱解析**。紫外/红外/核磁/质谱归在分析化学里（见分析化学的光谱章节），不占有机的时间。杂环是药科院校的重点，比综合类院校的通用考纲占比更高，所以单列一章。

### 常考题

按章节和常见考点自编，覆盖单选、多选、判断、简答。简答给的是「答题要点」——能复述出来才算真会。

# 导入题目：不用懂技术，三种入口

导航栏 **导入题目**，或者题库页「+ 导入题目」。

1. **拖入 PDF** —— 自动提取文字（PDF 库已内置在本地 `js/lib/`，离线也能用）
2. **拖入 TXT / MD** —— 直接读文本
3. **粘贴文本** —— 在 PDF 里 Ctrl+A 全选复制，粘进框里。**这招最万能**，扫描版 PDF 也能用（手机拍照转文字，或用微信/QQ 的提取文字功能）

解析器能认：题号 `1.` `56.` `1）`；选项 `A.` `A)` `A、` `A：` 以及**题干和选项挤在同一行**（PDF 复制最常见）；文末答案 `1-5 BCADB`、`答案：56-60 BDACA`、`1.B 2.C`、每题后跟的 `答案：B`；中文题干；页码干扰行。解析完进校对页，每道题都能改，改完存入题库。

> 扫描版（图片型）PDF 没有文字层，提取不到内容，请用粘贴方式。

## AI 接口（可选）

设置页填 OpenAI 兼容的 Base URL / Key / Model。配了之后：

- 词典没收录的词，鼠标划过去自动问 AI
- 生词本一键补全释义
- 导入题目时一键生成中文翻译和解析

不配也能正常用。Key 只存在本机浏览器里。从浏览器直连需要该服务允许 CORS。

## 数据存在哪

全部存在浏览器 localStorage 里。**换浏览器、清缓存、换设备都会丢**，重要的去设置页「导出全部数据」备份一份，换设备时再导入。

## 已知限制

- 内置的是按真题题型、分值、篇幅自编的**仿真卷**，不是真题（真题受版权保护）。拿到真题后用「导入题目」自己加。
- 听力用的是浏览器语音合成，音色比真人硬；考场会更容易。
- 扫描版 PDF 需要走粘贴入口。
