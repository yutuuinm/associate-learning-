# 备考台

一个本地运行的备考网站，目前装了两个考试：**CET-6** 和 **349 药学综合（沈阳药科大学）**。左侧栏顶部可以切换。

共同的设计目标：不是"检验你能考多少分"，而是**用最短时间把东西学会**——默认给方向、给定位，但**答案要你自己一层层揭开**。

## 怎么用

双击 `index.html` 即可，不需要联网、不需要装任何东西。建议在 Chrome 或 Edge 里打开（朗读功能需要系统语音）。

第一次进来先选考试：

- **CET-6**：会被引导做一次诊断，78 个词的词汇量测算（约 5 分钟）+ 8 道习惯问卷，自动生成训练方案。只做一次。
- **349**：直接进总览，选「带背」开始，或先翻「学霸笔记」建立骨架。

## 三个开关（顶栏常驻）

- **划词翻译**（三档）：`不显示` / `只词义` / `词义+整句`。想练**不看译文硬读**就选「不显示」，读不懂的句子再单独翻那一句。嫌一直弹就到「设置」里加**显示延迟**（0.3 / 0.6 / 1 秒），停留够了才出现，正常往下读不会被打扰。内置 322 条词典，收录的词带虚线下划线。
- **辅助提示**：四档
  - `模拟考试` = 什么都不给，做完才看解析
  - `轻` = 只给题型标签 + 该类题的解题口诀（不剧透）
  - `中` = 再加"去哪一段找"（默认）
  - `强` = 连正确答案和解析一起显示
- **即时反馈**：选完立刻判对错，不用等交卷

推荐流程：第一次「强」→ 隔天「中」→ 考前「模拟考试」。

## 效率工具（做题页）

做题页顶部有一条工具条：计时（超过建议时间会变红）、已答计数、逐句翻译、快捷键。

**宽屏（≥1160px）自动双栏**：左边文章、右边题目，各自独立滚动，不用来回翻。

### 划词与翻译（三档 + 三种粒度）

翻译这件事给了三种粒度，想看多少自己定：

- **整篇**：`T` 一次展开全文逐句译文
- **单句**：每句句尾（鼠标移上去出现）的 **`译`** 按钮，只翻这一句，就地显示中英对照 + 同步到底部译文条。想硬读又不至于卡死时用这个
- **任意一段**：划选后出现浮动条，点 `翻译` 做逐句对照；配了 AI 接口时，没有内置译文的段落也能翻

- **划选任意文字**就会浮出小工具条：`收词` / `翻译` / `复制`
  - 划的是**单个英文单词** → 「收词」可用；翻译时会在对照上方先给出**这个词的意思**
  - 划的是**任意一段** → 「翻译」可用
- **收词自动带例句**：存进生词本时会把**那句话一起存下来**（原文 + 译文 + 出自哪一篇），速记卡和生词本里都能看到，目标词在例句里**高亮标黄**。生词本表格点「例句」展开
- 快捷键：`S` 收词 · `R` 翻译划选的整段 · `T` 展开/收起全文逐句译文

### 找答案（`#/method` 手册 + 每题按钮）

这套东西的定位是**教你找到依据**，不是替你选。侧边栏「找答案手册」是完整的方法说明；做题时每道题都有 **`找答案`** 按钮（`F`），点开是四步：

1. **这题型怎么做** —— 主旨题先看首尾段、细节题必须有原文对应、态度题先砍极端项……按题型给的三句话打法
2. **拿什么去原文找** —— 自动从题干里揪出定位词（**数字、大写、专有名词、第几段**），告诉你这些词几乎不会被换词，扫它们最快
3. **哪些可以先排除** —— 逐项标注：
   - `有极端词，慎选`（完全 / 彻底 / 绝对 / 所有 / 必须 …）
   - `留有余地，更像答案`（可能 / 通常 / 部分 / 未必 …）
   - `几乎照抄原文依据，多半是干扰项`（用与原文译文的重合度判的）
   - `原文依据里找不到对应内容`
   - `这两项意思相反，答案多半在它俩里`
   点「在选项上标出来」会把标签直接写到选项后面
4. **实在读不懂** —— `猜一个`（`G`）按统计规律给一个概率最高的选项，并附上理由（砍极端 → 相反项二选一 → 留有余地 → 补分布最少的字母）

**关于第 4 步的重要提醒**：它会明说这是规律不是答案，还会告诉你——本站题库是自编的，干扰项为了教学写得比较明显，这些规律**在这里实测能蒙对九成，真题上大致只有一半**。它只是「不空题」的保底手段，练不出真本事。

放这条功能的目的不是让它替你做题，而是让你知道「原来还有这么一层套路」，然后仍然回到第 2、3 步去原文核对。

### 辅助提示系统

四档：`模拟考试`（无提示）/ `轻 · 方向` / `中 · 定位` / `强 · 全开`。档位决定的是**最多能开到第几级**，不是一口气全摊开。

- **按需逐级揭示**：做题时只先给「方向」。真的卡住了再点「还是没思路 → 告诉我在哪一段」，还不行才点「实在不会 → 看思路」
- **提示 3 只给思路，不直接报答案**——答案提交后自己核对。直接看答案练不出东西
- **提示记账**：每道题用了第几级提示都记下来。提交后会告诉你「这 N 题你开了提示，其中 M 题做对——这几题的分不算真会」，并给出**不开提示的正确率**，那才是你的真实水平
- **自适应建议**：最近无提示正确率 ≥80% 会建议收紧档位逼自己；≤45% 会建议放宽先把方法学会。统计页也能看到，可以「先不用」
- **错题重做自动升档**：从错题本点「只重做这几道」时，如果你当前档位低于「中 · 定位」，自动开到那一档（不覆盖你主动调高的设置）

### 逐层揭示解析（按 `E`）
不直接把答案拍在你脸上。四层，一层层点开：

1. **题型方向** —— 这类题该怎么想
2. **去原文哪里找** —— 定位提示
3. **可以先排除谁** —— 干扰项为什么错
4. **答案与完整解析** —— 这时候才给答案

### 其他辅助
- **定位原文**（`L`）：按题目里"原文依据"在文章里模糊匹配，黄色高亮并滚动过去
- **逐句翻译**（`T`）：一键展开全部句子译文，不用一个个 hover
- **题眼高亮**：题干里 mainly / infer / attitude / except 这类决定题型的词标红
- **绝对化词预警**：选项里 all / never / only / must 这类词加波浪线，通常可以先排除
- **错因自评**：每道错题下面点「定位错 / 句子没拆开 / 词汇卡住 / 粗心」，三种错法补法完全不同，会统计到数据分析页
- **收词**：选中任意单词按 `S` / `Tab`（或鼠标停在上面按 `S`）收进生词本
- **存摘抄**：选中一整段按浮动条的「存摘抄」，长难句先攒起来，别当场硬啃
- **查词**（`/`）：单词查释义 + 助记，句子查翻译 + 拆主干，查完直接入表

### 快捷键——但不想记也完全能用

- **做题页顶部工具条**：`‹ 上题` `下题 ›` `找答案` `猜一个` `解析` `定位原文` `逐句翻译` `收词` `译选中` `存摘抄` `查词` `清空` `快捷键 ?`
- **顶栏**：`查词`（`/`）与 `快捷键 ?` 常驻，任何页面都能点
- **每道题题头右侧**自带 `找答案` `解析` `定位` 三个小按钮，不用先跳到那题
- **每句句尾**的 `译` 按钮：只看这一句的中文
- **划选浮动条**：收词 / 存摘抄 / 查 / 翻译 / 复制

## 学习引擎

- **答题记录**：每次提交按题型记录，算正确率
- **六级得分预估**：按真题分值折算（讲座/仔细阅读 14.2 分每题、长对话/篇章/匹配 7.1、选词 3.55），没测过的题型用总正确率兜底并标「未测」；写译按全国平均 130 估
- **SRS 生词本**：SM-2 简化算法，三档评分（忘了 / 模糊 / 记得）决定下次复习间隔
- **错题库**：做错进库，连续做对 2 次毕业
- **打卡**：连续天数、70 天热力图、每日目标（15 / 30 / 50 / 80 题可调）

### 349 药学综合模块

沈阳药科大学自命题。**有机化学 + 分析化学 + 生物化学，每门 100 分，满分 300 分，题型不限**（2025 年起取消生理学，题型也不再是纯客观题）。

参考教材：胡春《有机化学》三版、邸欣《分析化学》八版、姚文兵《生物化学》八版。

### 带背（核心功能）

照着 B 站带背 up 主的思路做的：快、循环、可听、能挖空。

- **三种模式**
  - `跟读`：显示全文 + 朗读，跟着念
  - `填空`：自动把关键片段挖成空，先自己想，再对答案
  - `听背`：文字直接遮住，只放音，逼自己回忆
- **可调**：语速 0.7–1.5x、每条读 1–3 遍、条间 0.5–4 秒
- **范围**：全部 / 只背高频（常考指数 5 星）/ 只背收藏 / **只背不会+模糊** / **只背没标记过的** / 按科目 / 按单章
- **默写**：填空与听背模式下可以**打字作答**再对答案，系统用中文二元组覆盖率判分，告诉你命中了几个关键词、漏了哪段
- **自评**：每条都能标 `不会 / 模糊 / 会`，标记直接进入掌握度；标完自动跳下一条，适合一轮一轮刷
- **自动往下走**，背完一轮停住；进度记在本机，下次接着背
- **收藏**：按 `F` 收藏，之后可以只循环背收藏的

快捷键：`空格` 播放/暂停 · `←` `→` 切条 · `D` 显示答案 · `F` 收藏 · `1` `2` `3` 标不会/模糊/会

> 朗读用浏览器的语音合成。如果没装中文语音包会读不出来，页面底部会提示怎么装。

### 掌握度与错题本（学习闭环）

做题和带背不再各干各的，都汇到同一个账上：

- **掌握度** = 答题正确率（60%）+ 带背自评（40%），两者都有才算数，没测过的章显示「未测」
- 总览页、笔记页、章节页、顶栏都能看到；掌握度页按科目列出每章的掌握度，并直接点出**最薄弱的 3 章**
- **错题本**：做错自动进来，**连对 2 次自动毕业**，也可以手动标「已掌握」。每道错题下面直接带解析要点，一键跳回该章重做或去背
- 没选答案就点「查看解析」**不会**被判成错，避免一键把整章塞进错题本
- 349 的记录和 CET-6 完全分开，清空互不影响

### 学霸笔记

一句话一条，不废话。每条结构：

```
关键词   结论（一段说清）
         口诀：……（方便背）
```

### 反应机理（有机）

有机化学的分基本都在机理上。每个机理拆成三段看：

1. **分步**：每一步发生了什么
2. **箭头**：电子从哪流向哪（"谁进攻谁"）
3. **考点**：这个机理真正考的是什么、常见的坑

有机目前 **27 个机理**：自由基卤代、烯烃亲电加成（马氏）、过氧化物效应、溴鎓离子反式加成、Diels-Alder、共轭二烯 1,2/1,4、苯的亲电取代、傅-克烷基化重排、SN1/SN2 对比、E2 消除、醇的酸催化取代、酚的酸性、环氧乙烷酸碱开环（取向相反）、Claisen 重排、频哪醇重排、亲核加成、羟醛缩合（含脱水与交叉缩合）、Cannizzaro、卤仿反应、Michael 加成、Wittig、Baeyer-Villiger、酯化、Claisen 缩合、Beckmann 重排、重氮化。

有机另有三章「方法论」：**命名**（官能团优先顺序 / Z,E / 苯侧链母体判断）、**杂环化合物**（五元富电子 vs 六元缺电子、芳香性来源、五元取代在 2-位、吡啶亲核取代在 2/4-位、吲哚 3-位、稠环位置、酮-烯醇互变、常见药环辨识）、**合成与逆合成**（切断法、碳链增减、丙二酸酯 vs 乙酰乙酸乙酯、保护基、氧化放最后、先氧化后硝化的顺序陷阱）。

> **范围按沈药 349 走：不含波谱解析**。紫外/红外/核磁/质谱归在分析化学里（见分析化学的光谱章节），不占有机的时间。杂环是药科院校的重点，比综合类院校的通用考纲占比更高，所以单列一章。

# 导入题目：不用懂技术，三种入口

导航栏 **导入题目**，或者题库页「+ 导入题目」。

1. **拖入 PDF** —— 自动提取文字（PDF 库已内置在本地 `js/lib/`，离线也能用）
2. **拖入 TXT / MD** —— 直接读文本
3. **粘贴文本** —— 在 PDF 里 Ctrl+A 全选复制，粘进框里。**这招最万能**，扫描版 PDF 也能用（手机拍照转文字，或用微信/QQ 的提取文字功能）

解析器能认：题号 `1.` `56.` `1）`；选项 `A.` `A)` `A、` `A：` 以及**题干和选项挤在同一行**（PDF 复制最常见）；文末答案 `1-5 BCADB`、`答案：56-60 BDACA`、`1.B 2.C`、每题后跟的 `答案：B`；中文题干；页码干扰行。解析完进校对页，每道题都能改，改完存入题库。

> 扫描版（图片型）PDF 没有文字层，提取不到内容，请用粘贴方式。

- 生词本一键补全释义
- 导入题目时一键生成中文翻译和解析

不配也能正常用。Key 只存在本机浏览器里。从浏览器直连需要该服务允许 CORS。

## 词汇训练（六级 / 考研）

两套**分开背**的核心词库：六级 318 词、考研 318 词，都按频度分三档（高频 132 / 中频 123 / 低频 63）。

- **卷子是「生成」的，不是固定的一套**：每次从词库里现抽，点 `换一套` 重新抽
- **优先抽高频**：默认只抽 1 档。`只抽高频` / `高频+中频` / `三档全抽` 三个chip 随时切
- **两种题型**：`语境题`（从高频词文章的原句里挖空，考用法）+ `词义题`（考释义）
  - 语境题**只挖文章里真的出现过的词**——用词形还原匹配（supports → support），不会出现瞎挖的空
- **高频词文章**：六级 5 篇、考研 5 篇，本身就是用高频词写的。**文章对词库的覆盖率：六级 82 词（1 档 67）、考研 93 词（1 档 73）**
  - 每篇底部列出**这篇覆盖的核心词**，点一下就收进生词本，**例句是该词在文中的原句**
  - `在文中标出` 把覆盖词高亮到正文里（再点一次取消）
  - `用这篇出卷` 只考这篇里出现过的词，读完立刻测

## 每天 50 个生词（核心流程）

背单词最有效的方式不是背表，是**在你读不懂的那一刻把它收下来**。所以整套流程是：

**① 读文章 → 遇到不认识的词 → 选中它按 `Tab`**

- 选中一个词，按 <kbd>Tab</kbd> 直接收进生词本：**原文那句话自动跟着存进去**（英文 + 中文 + 出自哪一篇），收完选区自动清掉，可以直接接着挑下一个
- 不想用键盘就选完点浮动条的「收词」
- 任何入口收的词都算进今天的清单（词表页、文章页覆盖词、鼠标停留按 `S`）

**② 打开「今日新词」页，逐个过一遍**

每个词下面三件事：

- **AI 助记**（要联网 + 配了接口）：词根拆解 / 一句好记的助记法 / 常用搭配 / 一个六级难度的例句
- **练填空**：把例句里的这个词挖掉让你填回去。**不配 AI 也能练**——直接用原文那句挖空，判分时会认词形（单复数、时态），填错会告诉你正确写法
- **自评**：`忘了` / `模糊` / `记得` —— 直接接进 SRS，明天「生词速记」里先出现今天标「忘了」的

**③ 目标**

默认每天 **50 个**，可在今日新词页或设置页改成 20 / 30 / 50 / 80。总览页和侧边栏都有进度（侧边栏角标显示 `已收 / 目标`）。一篇六级阅读通常能收 10–20 个。

## 查词与摘抄本（AI 辅助学习的入口）

生词本收的是**一个词**（`Tab`），摘抄本收的是**一整段**。两条路都通到同一个地方：AI 帮你把它吃透。

**① 查词面板 —— 顶栏「查词」或按 `/`**

一个输入框解决三种需求，选中任何东西再按 `/` 会直接带进去：

- 查**单词**：内置词典释义 + AI 给的词根拆解 / 助记法 / 常用搭配 / 例句，下面直接是「收进生词本」——收完就能在今日新词页练填空
- 查**句子 / 段落**：自动挑出这段里出现的**核心词**（直接比六级和考研两套词表，**不依赖 AI**），点单个词或「全收进生词本」一次收走；配了 AI 还能「让 AI 拆这段」——主干 / 修饰成分 / 译文 / 生词一次讲完
- 查不到的词不会卡住：内置词典没有就走 AI 释义，AI 也没配就明确告诉你「去设置里填接口」，而不是留一片空白

**② 存摘抄 —— 选中一段 → 浮动条「存摘抄」**

- 摘抄时如果这段落在文章句子里，**内置译文会一起存下来**，之后能中英对照
- 摘抄本页面（侧边栏「摘抄本」）每段三个操作：**核心词 n**（挑着收或一键全收）、**AI 讲这段**、**复制**
- 摘抄的原文按词包起来，**悬停看释义、`Tab` 收词照常能用**——摘抄本本身也是一个阅读界面
- 存不进去不报错：同一段重复存只会提示「已经在摘抄本里了」

**③ 为什么分成两个本子**

| | 生词本 | 摘抄本 |
|---|---|---|
| 收什么 | 一个词 | 一整段 / 一个长句 |
| 怎么收 | 选中按 `Tab` | 选中点「存摘抄」 |
| 回来做什么 | AI 助记 → 练填空 → 自评进 SRS | AI 拆句子 → 把这段的核心词批量收进生词本 |

读文章时的正确用法：单词不认识就 `Tab` 收走，**句子读不懂别当场硬啃**，存进摘抄本，做完题再回来一起处理。

## AI 接口（可选，动态配置）

不填也能用（练填空走原文例句、核心词匹配走本地词表，都不依赖 AI）。填了之后多四件事：**给生词生成怎么记的助记**、词典没收的词自动问 AI、划选段落整段翻译、**拆长难句（主干 / 修饰 / 译文 / 生词）**。

三种配置方式任选：

1. **设置页填**：AI 接口区 → 启用 / base URL / key / 模型，保存后自动测连接
2. **URL 一次性带入**（不想手填时用）：打开 `index.html?aikey=你的key&aiurl=接口地址&aimodel=模型名`，配置写入本机后地址栏会自动清掉，密钥不会留在历史里
3. **存到你的数据库**：设置页「把配置存到云端」，换设备用「从云端读回来」。**默认不这么做**——因为这个页面是公开的，一旦上传，任何能打开它的人都能读到你的 key

地址和模型名是配套的，设置页有「一键填入」按钮：DeepSeek / Gemini / OpenAI / 智谱 GLM，点一下自动配对，你只粘 Key。

| 接口 | base URL | 模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | **`deepseek-flash`**（V4.1 Flash，快且便宜，助记和翻译够用）/ `deepseek-v4-pro`（拆长难句更稳） |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-flash-4.1` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |

注意：DeepSeek 现在的名字是 **`deepseek-flash`**（对应 V4.1 Flash）和 **`deepseek-v4-pro`**；旧名 `deepseek-chat` / `deepseek-reasoner` 已于 2026 年 7 月停用，`deepseek-v4-flash` 只是个别名（能用，但建议写 `deepseek-flash`）。模型名可以拿接口列出来核对：`GET https://api.deepseek.com/models`。

**思考型模型的一个坑（已在代码里兜住）**：V4 系列默认会先"想"一段，如果你给的 `max_tokens` 太小（比如 60），token 会全部烧在推理上，返回的正文是空字符串 —— 表现就是"AI 没返回内容"。所以请求里统一做了三件事：token 下限 600、默认带 `thinking:{type:"disabled"}`、接口不认这个字段时自动摘掉重试一次。

**密钥不要进仓库**（这个仓库是公开的，key 漏上去等于把额度送人）。三种做法任选：

1. **本机文件**（推荐，打开就配好）：`cet6-site/LOCAL-AI.js` 里填一次，打开 `index.html` 自动写进 localStorage。部署脚本会跳过名字里带 `LOCAL-` 的文件
2. **一次性链接**（适合线上那份）：打开 `https://你的域名/?aikey=你的key&aiurl=https://api.deepseek.com&aimodel=deepseek-flash`，配置写进浏览器后地址栏自动清掉
3. **设置页手填**：AI 接口区，点「DeepSeek Flash」一键填好地址和模型，只粘 Key

三重保险：`ghdeploy.js` 会跳过所有 `LOCAL-` / `-local.` 文件，并在上传前扫描 `sk-` / `sbp_` 密钥 —— 扫到就直接中止部署。另外，上传前会自动把 HTML 里对 `LOCAL-AI.js` 的引用删掉（线上没有这个文件，留着就是一条死链）。

### 「AI 没连上」先看这里

**顶栏右上角有个 AI 状态灯**：绿 `AI ✓` = 接好了，红 `AI ✕` = 没接上，**鼠标悬停能看到具体原因**，点一下直接去设置页。不用再猜。

常见原因和它显示的话：

| 灯 | 显示 | 怎么办 |
|---|---|---|
| 红 | `AI 未配置：缺 API Key` | 去设置页填 Key；线上那份没有内置密钥（公开仓库不能放），用一次性链接配一次 |
| 红 | `AI 未配置：没启用` | 设置页勾上「启用 AI」 |
| 红 | `HTTP 401（Authentication Fails）` | Key 不对、已被删掉或复制时缺了几位 |
| 红 | `HTTP 402` | 账户余额不足，去充值 |
| 红 | `HTTP 404 / 400 模型名` | 接口地址或模型名不对，点「DeepSeek Flash」一键重填 |
| 红 | `连不上接口：fetch failed` | 网络问题，或被浏览器拦了（看控制台 Network）。本地 `file://` 直连是通的，DeepSeek 允许跨域 |

设置页的「**自检一下**」会真发一个最小请求，把「通了 / 为什么没通」直接写在那一行，比看代码快。

## 账号（用户名 + 密码，数据各自独立）

**不登录也能用**——这是本地优先的离线站点，账号不是门禁。登录的作用是：把这台机器上的数据**划归到某个人名下**，之后一台机器几个人各用各的，互相看不到。

- **入口**：顶栏「账号」灯（蓝=已登录并显示名字，灰=未登录），或侧栏「系统 → 账号」
- **隔离是怎么做到的**：登录后所有学习数据的键统一加前缀 `u:<账号id>:`，A 和 B 在同一浏览器里也各存各的；退出后回到原来的公共区
- **首次登录会问一次**：这台机器上还没归属的数据要不要一起搬进这个账号（选否就从空白开始）
- **密码**：只存 PBKDF2-HMAC-SHA256（6 万轮）的哈希 + 随机盐，**明文不落盘**。忘了只能删号重来，找不回来
- **换设备不会自动跟过来**：用设置页「导出 / 导入」搬（导出的文件只含当前账号的数据），或者开云端备份
- 账号表和当前会话是站点级的，不跟着账号走——不然切个账号连账号本都找不着了

顶栏灯旁边有账号名；点开能看到这个账号建于何时、名下多少项数据，可以改密码、改名字、切换到别的账号（要输密码），或者连数据一起删掉。

## 云端备份（Supabase，可选）

把**生词本、答题记录、每日新词、AI 助记缓存、摘抄本**备份到你自己的数据库，换设备、清缓存都不怕。

**云端也按账号分开**：每张表都有 `user_id` 列，主键是 `(user_id, ...)`,所以两个账号背同一个词也不会互相覆盖；查询一律带 `user_id` 过滤。

- **没登录时**同步的数据落在 `anon` 公共区（谁都能看到）——设置页会红字提示你
- **登录后**同步到自己的账号 id 名下，设置页「数据归属」会显示是谁
- 换账号后同步进度（上传到哪天为止）也是各算各的，不会从别人的进度接着传

- **本地优先**：云挂了、网断了照样能学，只是不同步，失败最多提示一次不刷屏
- **合并策略**：生词本按更新时间取新的（谁新听谁的）；每日新词、助记缓存、摘抄本取并集；答题记录只增量上传。摘抄本额外记一个「本地最后改动时间」——本地改得比云端晚就只推不拉，这样**清空摘抄本也能同步下去**，不会被云端又拉回来
- **开关**：设置页「云端备份」——启用 / 自动同步（改动 4 秒后触发）/ 立即同步 / 测试连接 / 只从云端拉回
- 需要填项目 URL 和 **anon key**（后台 Settings → API Keys）。anon key 本来就是给前端用的；**不要填 service_role key**

## 数据存在哪

默认全部存在浏览器 localStorage 里。**换浏览器、清缓存、换设备都会丢**，重要的去设置页「导出全部数据」备份一份，换设备时再导入。

想省掉这一步就开「云端备份」（上一节）——填一次 Supabase 的 URL 和 anon key，之后生词和进度自动备份到你的库里。

## 已知限制

- 内置的是按真题题型、分值、篇幅自编的**仿真卷**，不是真题（真题受版权保护）。拿到真题后用「导入题目」自己加。
- 摘抄本的「核心词」是按词表匹配的（含单复数 / 时态 / -ing / -ly 变形），所以短词（4 字母以内）不参与匹配以免误报；像 *exposure* 这种不在两套词表里的词也不会被挑出来。
- 「AI 拆句子」和「AI 助记」都由模型生成，例句和释义**要回原文再对一遍**。
- 听力用的是浏览器语音合成，音色比真人硬；考场会更容易。
- 扫描版 PDF 需要走粘贴入口。
- **账号密码只存在这台浏览器里**，不是服务器账号：换设备要用导出/导入或云端备份搬，密码忘了删号重来。
- **云端隔离是"逻辑隔离"**：同行数据靠 `user_id` 分开、互不覆盖，但因为前端只用 anon key（没有登录态），拿到 key 的人仍能读到库里的全部数据。要做到"别人绝对读不到"，得给项目开 Supabase Auth 并把访问规则改成 `auth.uid() = user_id`；在那之前，**别把 anon key 发给不信任的人**，也别在公共区存隐私内容。
