# CET-6 训练台

一个本地运行的六级备考网站。设计目标不是"检验你能考多少分"，而是**用最短时间把题学会**——所以默认给方向、给定位，但**答案要你自己按一层层揭开**。

## 怎么用

双击 `index.html` 即可，不需要联网、不需要装任何东西。建议在 Chrome 或 Edge 里打开（听力需要英文语音）。

第一次进来会被引导做测评：**78 个词的词汇量测算（约 5 分钟）+ 8 道题的习惯问卷**，做完自动生成一套针对你的训练方案。测评结果存在本机浏览器里，只做一次。

## 页面

| 页面 | 作用 |
|---|---|
| 总览 | 预估六级得分（环形）、今日题量/目标、连续打卡、待复习生词、今日三件事、题型短板 |
| 测评 | 词汇量分层测算 + 答题习惯诊断 |
| 方案 | 根据测评结果生成的词汇策略 / 题型优先级 / 每周时间表 |
| 题库 | 阅读 4 篇、听力 7 篇、长篇匹配 1 篇、选词填空 1 篇，带完成度 |
| 生词速记 | SRS 间隔重复卡片 + 词表，做阅读时按 `S` 随手收词 |
| 错题本 | 只收做错过的题，连续做对 2 次自动毕业；可「只重做这几道」 |
| 数据分析 | 折算六级得分、分丢在哪、错因分布、打卡热力图、每日目标 |
| 导入题目 | 传 PDF / TXT / 粘贴文本 → 自动拆出题目 → 核对后入库 |
| 设置 | 提示开关、AI 接口、数据导出导入 |

## 三个开关（顶栏常驻）

- **划词提示**：划到单词弹释义；划到句子，页面底部显示整句翻译。内置 322 条词典，收录的词带虚线下划线。
- **辅助提示**：四档
  - `模拟考试` = 什么都不给，做完才看解析
  - `轻` = 只给题型标签 + 该类题的解题口诀（不剧透）
  - `中` = 再加"去哪一段找"（默认）
  - `强` = 连正确答案和解析一起显示
- **即时反馈**：选完立刻判对错，不用等交卷

推荐流程：第一次「强」→ 隔天「中」→ 考前「模拟考试」。

## 效率工具（做题页）

做题页顶部有一条工具条：计时（超过建议时间会变红）、已答计数、逐句翻译、快捷键。

**宽屏（≥1160px）自动双栏**：左边文章、右边题目，各自独立滚动，不用来回翻。

### 逐层揭示解析（按 `E`）
不直接把答案拍在你脸上。四层，一层层点开：

1. **题型方向** —— 这类题该怎么想
2. **去原文哪里找** —— 定位提示
3. **可以先排除谁** —— 干扰项为什么错
4. **答案与完整解析** —— 这时候才给答案

### 其他辅助
- **定位原文**（`L`）：按题目里"原文依据"在文章里模糊匹配，黄色高亮并滚动过去
- **逐句翻译**（`T`）：一键展开全部句子译文，不用一个个 hover
- **题眼高亮**：题干里 mainly / infer / attitude / except 这类决定题型的词标红
- **绝对化词预警**：选项里 all / never / only / must 这类词加波浪线，通常可以先排除
- **错因自评**：每道错题下面点「定位错 / 句子没拆开 / 词汇卡住 / 粗心」，三种错法补法完全不同，会统计到数据分析页
- **收词**：选中任意单词按 `S`（或鼠标停在上面按 `S`）收进生词本

### 快捷键
| 键 | 作用 |
|---|---|
| `1`–`4` / `A`–`D` | 选择选项 |
| `J` / `K` | 下一题 / 上一题 |
| `E` | 逐层展开解析 |
| `L` | 定位到原文依据 |
| `T` | 逐句翻译开关 |
| `S` | 收词进生词本 |
| `Enter` | 提交 |
| `?` | 快捷键面板 |

## 学习引擎

- **答题记录**：每次提交按题型记录，算正确率
- **六级得分预估**：按真题分值折算（讲座/仔细阅读 14.2 分每题、长对话/篇章/匹配 7.1、选词 3.55），没测过的题型用总正确率兜底并标「未测」；写译按全国平均 130 估
- **SRS 生词本**：SM-2 简化算法，三档评分（忘了 / 模糊 / 记得）决定下次复习间隔
- **错题库**：做错进库，连续做对 2 次毕业
- **打卡**：连续天数、70 天热力图、每日目标（15 / 30 / 50 / 80 题可调）

## 导入题目：不用懂技术，三种入口

导航栏 **导入题目**，或者题库页「+ 导入题目」。

1. **拖入 PDF** —— 自动提取文字（PDF 库已内置在本地 `js/lib/`，离线也能用）
2. **拖入 TXT / MD** —— 直接读文本
3. **粘贴文本** —— 在 PDF 里 Ctrl+A 全选复制，粘进框里。**这招最万能**，扫描版 PDF 也能用（手机拍照转文字，或用微信/QQ 的提取文字功能）

解析器能认：题号 `1.` `56.` `1）`；选项 `A.` `A)` `A、` `A：` 以及**题干和选项挤在同一行**（PDF 复制最常见）；文末答案 `1-5 BCADB`、`答案：56-60 BDACA`、`1.B 2.C`、每题后跟的 `答案：B`；中文题干；页码干扰行。解析完进校对页，每道题都能改，改完存入题库。

> 扫描版（图片型）PDF 没有文字层，提取不到内容，请用粘贴方式。

## AI 接口（可选）

设置页填 OpenAI 兼容的 Base URL / Key / Model。配了之后：

- 词典没收录的词，鼠标划过去自动问 AI
- 生词本一键补全释义
- 导入题目时一键生成中文翻译和解析

不配也能正常用。Key 只存在本机浏览器里。从浏览器直连需要该服务允许 CORS。

## 文件结构

```
index.html          骨架：侧边栏 + 顶栏 + 内容区
css/style.css       设计系统（配色/间距/组件/响应式）
js/dict.js          322 条内置词典
js/bank-reading.js  仔细阅读 4 篇 + 选词填空 + 长篇匹配
js/bank-other.js    听力 7 篇 + 写作 + 翻译
js/assess.js        词汇量词表 + 习惯问卷 + 方案生成
js/core.js          设置 / 划词 / AI 接口 / 题型口诀
js/stats.js         学习引擎：记录 / 统计 / 得分预估 / SRS / 错题
js/tools.js         效率工具：快捷键 / 逐层揭示 / 定位 / 计时 / 环形图
js/import.js        PDF、TXT 导入与校对
js/app.js           路由与全部页面渲染
js/lib/             pdf.js（离线内置）
```

## 数据存在哪

全部存在浏览器 localStorage 里。**换浏览器、清缓存、换设备都会丢**，重要的去设置页「导出全部数据」备份一份，换设备时再导入。

## 已知限制

- 内置的是按真题题型、分值、篇幅自编的**仿真卷**，不是真题（真题受版权保护）。拿到真题后用「导入题目」自己加。
- 听力用的是浏览器语音合成，音色比真人硬；考场会更容易。
- 扫描版 PDF 需要走粘贴入口。
