# CET-6 训练台

一个本地运行的六级备考网站。设计目标不是"检验你能考多少分"，而是**用最短时间把题学会**——所以所有提示默认全开。

## 怎么用

双击 `index.html` 即可，不需要联网、不需要装任何东西。建议在 Chrome 或 Edge 里打开（听力需要英文语音）。

第一次进来会被引导做测评：**78 个词的词汇量测算（约 5 分钟）+ 8 道题的习惯问卷**，做完自动生成一套针对你的训练方案。测评结果存在本机浏览器里，只做一次。

## 五个页面

| 页面 | 作用 |
|---|---|
| 首页 | 词汇量、剩余天数、今日任务；三个提示开关 |
| 测评 | 词汇量分层测算 + 答题习惯诊断 |
| 方案 | 根据测评结果生成的词汇策略 / 题型优先级 / 每周时间表 |
| 题库 | 阅读 4 篇、听力 7 篇、选词填空 1 篇、长篇匹配 1 篇 |
| 设置 | 提示开关、AI 接口、导入试卷、清空数据 |

## 三个开关（首页和做题页都有）

- **鼠标移到词上给提示**：划到单词弹释义；划到句子，页面底部显示整句/整段翻译。内置 322 条词典，收录的词带虚线下划线。
- **辅助提示**：四档
  - `关闭` = 模拟考试，做完才看解析
  - `轻` = 只显示题型标签 + 该类题的解题口诀（不剧透）
  - `中` = 再加"去哪一段找"的定位提示
  - `强` = 连正确答案和解析一起显示（第一次学时用这个）
- **即时反馈**：选完立刻显示对错和解析，不用等交卷

建议流程：第一次用「强」把题做一遍 → 隔天用「中」重做 → 考前用「关闭」模拟。

## 关于真题：为什么不内置，以及怎么装进去

**本站不内置任何真实真题。** 2005–2026 的六级真题版权归教育部考试中心所有，无法通过合法渠道批量获取，也不能复制分发。内置的是按真题的题型、分值、篇幅**自编的仿真卷**，难度和出题思路对齐真题，但不会和你 12 月考的那套重合。

如果你手上有真题（出版的真题集、学校发的资料），可以在**设置 → 导入试卷**里粘进来，之后它会出现在题库里。格式：

```json
{
  "type": "reading",
  "id": "MY01",
  "title": "文章标题",
  "topic": "科普",
  "text": [
    ["English paragraph...", "中文翻译..."],
    ["第二段英文", "第二段中文"]
  ],
  "qs": [
    {
      "n": 1,
      "type": "main",
      "q": "What is the passage mainly about?",
      "o": ["选项A", "选项B", "选项C", "选项D"],
      "a": 1,
      "loc": "原文依据（英文）",
      "locZh": "原文依据（中文）",
      "why": "为什么选它",
      "trap": ["干扰项A错在哪", "C错在哪", "D错在哪"],
      "l2": "提示2：去哪一段找",
      "guess": "没读懂时怎么猜"
    }
  ]
}
```

字段说明：

- `type`：`reading` / `listening` / `cloze` / `matching`
- 题目 `type`：`main` 主旨 / `detail` 细节 / `meaning` 词义句意 / `attitude` 态度 / `infer` 推断（决定显示什么解题口诀）
- `a`：正确选项下标，**从 0 开始**
- `locZh`、`l2`、`guess`、`trap` 都可以省略，缺了就不显示那一块
- `text` 每一段是 `[英文, 中文]` 的数组；中文用于划句翻译。没有中文就写 `["英文","英文"]`

导入的内容存在浏览器 localStorage 里，换浏览器或清缓存会丢。重要的试卷建议把 JSON 单独存一份。

## AI 接口（可选）

不填也能用。填了之后：

1. 内置词典查不到的词，会自动问 AI 补释义（结果缓存在本地，同一个词只问一次）
2. 你可以自己扩展用途（改 `js/core.js` 里的 `aiChat`）

配置在**设置 → AI 接口**，需要 Base URL、Key、模型名，兼容 OpenAI 的 `/chat/completions` 格式。填完点"保存并测试连接"会用一个单词试一次。

注意两点：Key 只存在你本机；浏览器直连 API 需要对方允许跨域（CORS），国内部分服务可能需要走代理。

## 文件结构

```
index.html            页面骨架
css/style.css         样式
js/dict.js            内置词典（322 条，可自行往里加词条）
js/bank-reading.js    题库：4 篇仔细阅读 + 选词填空 + 长篇匹配
js/bank-other.js      题库：7 篇听力 + 写作 + 翻译
js/assess.js          测评：词频分层词表 + 问卷 + 方案生成逻辑
js/core.js            设置 / 划词引擎 / AI 接口 / 题型解题口诀
js/app.js             路由与页面渲染
```

要加文章：往 `js/bank-reading.js` 的 `readings` 数组里按同样格式加一项即可，不用改别的。

## 已知限制

- 选词填空和长篇匹配的解析比阅读简略（这两块分值低，投入产出比不划算）
- 听力用浏览器语音合成朗读，机器音比真人录音硬，实际考试会更容易
- 词汇量是分层抽样估算，误差约 ±300，看趋势比看绝对值有用
